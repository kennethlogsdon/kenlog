# KenLog ── 3D Art, UI Design & Web Dev Blog

Welcome to **KenLog**, a personal technical blog and design journal by Kenneth Lee Logsdon. This space is dedicated to exploring the intersection of hard-surface 3D modeling, pixel-perfect user interface design, and modern front-end web development.

🔗 **Live Site:** [https://kennethlogsdon.github.io/kenlog/](https://kennethlogsdon.github.io/kenlog/)

---

## 🎨 What is KenLog?

KenLog serves as a central hub for sharing tutorials, workflows, and breakdowns of digital creation. The blog focuses on three core domains:

1. **3D Modeling & Rendering**: Workflows inside **Blender**, specializing in hard-surface asset creation, non-destructive subdivision sculpting, and Cycles lighting layouts.
2. **UI/UX Aesthetics**: Guidelines and case studies on constructing modern user interfaces, specializing in visual hierarchy, accessibility, and styles like glassmorphism.
3. **Web3D & Front-end**: Optimization techniques to load and render interactive 3D assets (`.glb` / `.gltf` files) in real-time on standard web pages using minimal resources.
